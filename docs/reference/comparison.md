# Сравнение Meshtastic и MeshCore

## Обзор платформ

Обе платформы — **Meshtastic** и **MeshCore** — предназначены для создания LoRa mesh-сетей офлайн-связи. У них разный подход к маршрутизации и организации сети.

---

## Основные отличия

|  | **MeshCore** | **Meshtastic** |
|---|---|---|
| **Маршрутизация** | Поиск пути → передача **по маршруту** | В основном **managed flood** (переизлучение по сети с ограничениями) |
| **Доставляемость** | После нахождения маршрута пакеты идут по цепочке репитеров к конкретному адресату | Flood хорошо разносит сообщение по округе; в очень плотной или длинной сети растёт нагрузка на эфир |
| **Дальность через mesh** | До **64** переходов (hop); при path hash 2 байта — до **32**. Теоретическая дальность сети — число hop × дальность одного радиопрыжка | По умолчанию **3** hop, максимум в прошивке **7**. Теоретическая дальность сети — до 7 × дальность одного прыжка |
| **Роли устройств** | Явно определены: клиент / репитер / room server | Узлы чаще универсальнее, роли менее жёсткие |
| **История сообщений** | Отдельный **room server**, который доставит вам все пропущенные сообщения, пока вас не было в сети | История только тех сообщений, которые удалось принять вашему LoRa-устройству. Если сообщение до вас по каким-либо причинам не дошло, получить его уже не получится |
| **Простота настройки** | Требует понимания ролей и структуры сети | Быстрый старт, более простая начальная настройка |
| **Экосистема** | Растущее сообщество, активная разработка | Большое глобальное сообщество, обширная документация |

---

## Когда выбрать Meshtastic

✅ Вам нужен **быстрый старт** без глубокого погружения  
✅ Планируете **небольшую сеть** (до 3-7 переходов)  
✅ Нужна **простая настройка** и универсальные узлы  
✅ Важна **широкая поддержка** оборудования и приложений  
✅ Хотите подключиться к существующим сетям Meshtastic  

---

## Когда выбрать MeshCore

✅ Нужна **большая сеть** с множеством переходов (до 32-64 hop)  
✅ Важна **чёткая структура** с выделенными ролями (репитеры отдельно от клиентов)  
✅ Необходима **история сообщений** через room server  
✅ Хотите **оптимизированную маршрутизацию** по найденному пути  
✅ Планируете расширяемую инфраструктуру с выделенными узлами  

---

## Можно ли использовать обе платформы?

**Нет**, Meshtastic и MeshCore используют разные протоколы и не совместимы между собой напрямую. Устройства на разных платформах не смогут обмениваться сообщениями.

Однако в одном географическом регионе могут существовать **отдельные сети** на каждой платформе, работающие на разных частотах.

---

## Рекомендации для MeshNetBY

В сети **MeshNetBY** поддерживаются **обе платформы**:

- **Meshtastic** — частота 869.525 МГц (preset MEDIUM_FAST)
- **MeshCore** — частота 869.618 МГц (EU/UK Narrow)

Выбирайте платформу в зависимости от ваших задач и присоединяйтесь к соответствующей сети!
