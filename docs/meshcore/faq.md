# FAQ по MeshCore
## Ответы на вопросы специфичные для MeshCore

!!! info "Общие вопросы"
    Общие вопросы об устройствах, диапазонах и участии в сети смотрите в разделе [Вопрос Ответ](/faq).

### В чём отличие MeshCore от Meshtastic?

**MeshCore** и **Meshtastic** — это две разные платформы для создания LoRa mesh-сетей. Основные отличия:

- **Маршрутизация**: MeshCore использует поиск пути с последующей передачей по найденному маршруту, Meshtastic — managed flood
- **Дальность**: MeshCore поддерживает до 32-64 переходов (hop), Meshtastic — до 3-7
- **Роли**: в MeshCore чёткое разделение на клиент/репитер/room server
- **История**: MeshCore имеет отдельный room server для сохранения истории сообщений

Подробное сравнение смотрите в разделе **[Справочник → Сравнение платформ](/reference/comparison)**.

### Какие роли устройств есть в MeshCore?

В MeshCore устройства имеют явно определённые роли:

1. **Companion (Chat / клиент)** — для обычного участия: чаты, объявления, личные сообщения через приложение на телефоне.

2. **Repeater (ретранслятор)** — принимает и пересылает чужие пакеты, расширяет покрытие сети. Это основа mesh-сети.

3. **Room server** — хранит историю сообщений комнаты, доставляет пропущенные сообщения.

Одно устройство можно прошить в любую роль, но нельзя совмещать роли на одном устройстве.

### Чем Companion отличается от Repeater?

**Companion** — ваш **мобильный** узел для приёма и отправки сообщений через приложение на телефоне. Он используется для обычного участия в сети: чаты, объявления, личные сообщения.

**Repeater** — узел, который **специально** принимает и пересылает чужие пакеты, расширяет покрытие сети. Это основа mesh-сети.

!!! tip "Важно"
    Для расширения покрытия сети нужен именно **repeater**, установленный повыше: на балконе, крыше или высоком этаже. Companion не раздаёт чужой трафик дальше.

### Зачем room server, если есть чат?

Обычный чат в mesh — это в первую очередь **«живой эфир»**: сообщение уходит в радиосеть и его слышат те, кто **прямо сейчас онлайн** (устройство включено и находится в зоне радиосвязи — напрямую или через репитеры).

Если в этот момент ваше LoRa-устройство **выключено**, разрядилось или вы **вышли из покрытия сети**, пакет до вас **физически не дойдёт**. Когда вы снова включитесь или вернётесь, «старое» сообщение само по воздуху уже не появится: эфир его не хранит, как облачный мессенджер.

**Room server** — отдельный узел-«сервер комнаты», который остаётся в сети и:

- принимает сообщения комнаты и **сохраняет историю**
- когда вы снова онлайн, отдаст **неполученные** сообщения из истории
- работает как общая «тетрадь» района: написали, пока вас не было — потом можно дочитать

**Грубо:** чат без room server — разговор по рации «кто на связи сейчас»; room server — щит с копиями сообщений, из которого можно забрать то, что пропустили, пока были офлайн.

!!! warning "Важно"
    Room server **не заменяет** репитер для расширения покрытия. История — отдельно, пересылка пакетов на расстояние — у repeater.

### Можно ли использовать MeshCore и Meshtastic вместе?

**Нет**, устройства на MeshCore и Meshtastic не могут напрямую обмениваться сообщениями, так как используют разные протоколы.

В сети MeshNetBY работают **две отдельные сети**:

- **Meshtastic** — частота 869.525 МГц (preset MEDIUM_FAST)
- **MeshCore** — частота 869.618 МГц (EU/UK Narrow)

Выбирайте одну платформу и настраивайте устройство под соответствующую сеть.
