## О проекте MeshNetBY
Мы интересуемся автономными mesh-сетями и строим сеть на базе платформ [Meshtastic](https://meshtastic.org/) и [MeshCore](https://meshcore.io/) в городе Минск (РБ), которая использует недорогие LoRa-радиомодули для создания беспроводной сети с большой дальностью действия.

Наша цель — создать устойчивую, децентрализованную и сообщественную сеть, которая может обеспечить связь в условиях отсутствия традиционных сетей, поддерживать местные мероприятия и способствовать сотрудничеству между участниками.

Мы приветствуем как новичков, так и опытных участников — вместе мы строим независимую сеть связи.

!!! info "MeshCore в MeshNetBY"
    Наша сеть поддерживает **обе платформы**: Meshtastic и MeshCore. Если вы хотите использовать MeshCore, ознакомьтесь с [руководством по настройке MeshCore](/meshcore/meshcore) и используйте рекомендуемые параметры для совместимости с нашей сетью.

### Миграция на MEDIUM_FAST
!!! info "Информация"
    Начиная с 18 мая 2026 года, участники сети переключили свои узлы на предустановленный модем MediumFast. Для получения дополнительной информации о настройке подключенных узлов см. [наше руководство по настройке](/meshtastic/start).

### Платформы и настройки

Наша сеть поддерживает **две платформы**: Meshtastic и MeshCore.

#### Meshtastic — настройки MediumFast

| Параметр | Значение |
|----------|----------|
| Modem Preset | **MEDIUM_FAST** |
| Region | **EU_868** |
| Frequency Slot | **0** (869.525 MHz) |

Полное руководство: **[Настройка Meshtastic →](/meshtastic/start)**

#### MeshCore — настройки для сети

| Параметр | Значение |
|----------|----------|
| Preset | **EU/UK (Narrow)** |
| Frequency | **869.618 МГц** |
| Bandwidth | **62.5 кГц** |
| Spreading Factor | **8** |
| Coding Rate | **8** |
| TX Power | **22 дБм** |

Полное руководство: **[Настройка MeshCore →](/meshcore/meshcore)**
